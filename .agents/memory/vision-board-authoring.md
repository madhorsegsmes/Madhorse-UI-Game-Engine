---
name: Vision Board authoring
description: Node-level authoring and non-destructive reference-media expectations.
---

Every Vision Board node is independently editable: creators can change its name and purpose and attach menu screens, reference or scene images, videos, and audio to that same node. Do not make creating a separate media node the only attachment path.

**Why:** The user asked to place this content “in each node,” change each node's name and point, and apply creative effects to images and videos.

**How to apply:** Keep node content independent of its position in the skill tree. Preserve existing node content and media when changing layout or migrating saved boards.

New Vision Boards default to Basic with only a Start node. Creators add their own intermediate nodes and must add a Finish node to complete the plan.

**Why:** The user explicitly requested a Start-only default rather than pre-populated mission and finish nodes.

**How to apply:** Allow incomplete drafts to save. Do not insert mission or finish nodes automatically, including during migration; preserve existing boards.

Creative effects are non-destructive presentation settings, not changes to the original media bytes. Menu templates are authoring previews until explicitly connected to runtime or export behavior.

**Why:** Creators need to edit and reset references without losing their originals; displaying a menu mockup does not establish game functionality.

**How to apply:** Preserve originals when adding media editing or export. Clearly distinguish board previews from baked video output or working game menus.
